## 一句话结论

当前 MVP 是 **经验驱动的规则式 Python 爬虫**（列表启发式抽链 + DOM/trafilatura 抽字段）。对结构规矩的静态站可用；对门户/卡片/怪 DOM/翻页能力不足。  
若要提高准确率，不宜用 Agent 替换整条批量采集，而应 **规则主路径 + Agent 旁路修复**；生产编排偏 LangGraph，怪站攻坚偏 Claude Agent SDK，解析器代码进化可用 Cursor SDK。
