# 公司发布平台环境变量（华院规则二评分服务）

> 核对时间：2026-10-20（相对规则二 v3 flow、`backend/app/config.py`、`requirements-huayuan.txt`）。  
> 结论：镜像构建不打密钥（`.dockerignore` 已排除 `.env`）；发布时按下面注入。  
> 只保留规则二评分：`/api/v1/huayuan/radar-event-score` + `radar_score` event worker。

## Agent `unidt-exhibition-opportunity-py-agent`

容器端口：`8000`  
K8s 服务名：`exhibition-opportunity-agent`（展厅 Java 的 `AGENT_BASE_URL` 指向它）

### 必配

```text
HUAYUAN_API_KEY=<公司网关 key>
DEEPSEEK_SEARCH_KEY=<DeepSeek key>
EXHIBITION_MYSQL_HOST=<host>
EXHIBITION_MYSQL_PORT=3306
EXHIBITION_MYSQL_USER=<user>
EXHIBITION_MYSQL_PASSWORD=<password>
EXHIBITION_MYSQL_DB=unidt_exhibition
```

| 变量 | 作用 |
|------|------|
| `HUAYUAN_API_KEY` | **华院 LLM 主密钥**。`config/model_providers.yaml` 的 `provider: huayuan` 读它；规则二 react / auditor 节点都用它。 |
| `DEEPSEEK_SEARCH_KEY` | 规则二 v3 唯一检索链（DeepSeek Search / Fetch）。未配置时 event worker 暂停认领任务。 |
| `DEEPSEEK_API_KEY` | 可选回退：未配 `DEEPSEEK_SEARCH_KEY` 时使用。 |
| `EXHIBITION_MYSQL_*` | 任务 `radar_event_job`、事件 `radar_event` / `radar_event_evidence`、区域字典 `region` / `region_alias`。 |

### event worker

| 变量 | 默认 | 作用 |
|------|------|------|
| `RADAR_SCORE_WORKER_IN_APP` | `false` | `true` 时在 FastAPI lifespan 内启动 event worker；也可保持 false，另起 `python -m radar_score`。 |
| `RADAR_SCORE_EVENT_CONCURRENCY` | `2` | 同时处理的 event 任务数。 |
| `RADAR_SCORE_POLL_INTERVAL_SEC` | `15` | 无任务时轮询间隔。 |
| `RADAR_SCORE_STALE_TIMEOUT_SEC` | `2400` | RUNNING 超时回收。 |
| `RADAR_SCORE_SHUTDOWN_WAIT_SEC` | `30` | 停止时等待在途任务。 |
| `RADAR_SCORE_MAX_RETRY` | `3` | 可重试错误的最大重试次数。 |
| `RADAR_TENANT_ID` | 空 | 可选：只认领指定租户任务。 |

### 可选

| 变量 | 作用 |
|------|------|
| `LANGFUSE_ENABLED` / `LANGFUSE_PUBLIC_KEY` / `LANGFUSE_SECRET_KEY` / `LANGFUSE_BASE_URL` | 可观测性；镜像不装 `langfuse` 包，未启用时自动降级。 |

### 不要再配

`ANTHROPIC_*`、`ANY_SEARCH_API_KEY`、`ANY_SEARCH_API_KEYS`、`BO_CHA_APIKEY`、`MILVUS_*`、`HUAYUAN_API_URL_embeddings`、`EMBEDDING_*`、`NEWS_CRAWL_*`、`NEWS_CONTENT_*`、`RADAR_KB_*`、`ENABLE_DATABASE`、`DATABASE_URL`、`DOUBAO_API_KEY`、`OPENAI_API_KEY`。

规则二 v3 不再召回 Milvus / 知识库；这些变量不会生效，配了只会造成误解。
