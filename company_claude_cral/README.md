## 相对既有分析，本目录新增的判断

既有 `company_news_crawl/实验/` 下的分析已经相当扎实，本目录**不推翻**它，但补了四点：

1. **翻页能力只有 1/6，且唯一"生效"的站是关键词蒙中** —— 既有文档记"1/6 生效"，这个数是**对的**（本目录初稿一度误判为 0/6，已核对源码更正）。但需补充归因：那唯一一站（华岭股份）能成功，是因为它的翻页/文章 URL 都落在 `/news/` 下、撞上 `NEWS_KEYWORDS` 里的 `news` 子串，**不是翻页发现逻辑正确**；而唯一被人工逐条核对过的平安，`index_2.shtml` 有 25 条全新链接、规则版命中 **0/25**。见 `01` §2。
2. **Agent 的价值被高估在抽链上、被低估在"定界与清洗"上** —— 平安实验 25/25 的命中，是因为 `simplify_list_html` 已经用规则做了同域过滤 + href 归一化，Agent 拿到的是一份干净链接清单。Agent 真正的增量是**辨识**（哪条是新闻、哪条是翻页），不是**发现**。这决定了它值不值得花 LLM 的钱。见 `02`。
3. **翻页发现与详情抽取是两个独立难题，不能打包论证** —— 现有 Agent 实验只证明了翻页发现；详情抽取（日期落进正文、许可证公示污染）**明确仍失败**。见 `02`。
4. **给 Agent 卖"少 token"是错的卖法** —— 单站 $0.48~0.82，相对纯规则无成本，token 是净增。Agent 唯一的正当性来自**减少人工**（未命中先验的站、每次改版的人工修规则）。见 `02`。

## 一句话立场

**不是"用 Agent 替换爬虫"，也不是"Agent 只做失败修复"。**
是 **规则做确定性抽锁 + Agent 做定界/清洗/修复 + 沉淀 site_profile 回到规则** 的两层闭环；
单站篇篇开 Agent 不成立，**按站族 + 冷启动一次性 Agent 摊销**才成立。
