## 3. 运行与上线注意

1. **必须先在 exhibition MySQL 执行** `scripts/sql/18_radar_news_agent_guard.sql`（或合入 Java 侧同名脚本），再启动 worker。  
2. 表不存在时：规则成功任务不受影响；规则失败走 Agent 时，`MysqlAgentGuardStore` 会因缺表报错——上线前确认 DDL。  
3. 运维语义不变：闸门按日重置 **不会** 自动把已 `FAILED` 的 task 改回 `PENDING`。  
4. 可选配置：`.env` 增加 `NEWS_CONTENT_AGENT_MAX_CONTENT_FAILURES_PER_SITE=1`（与代码默认一致时可省略）。
