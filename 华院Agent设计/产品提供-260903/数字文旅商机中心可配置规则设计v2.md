# 数字文旅商机中心可配置规则设计

## 1. 四类规则总览


| 规则                     | 解决的问题              | 主要输入             | 主要输出                      |
| ---------------------- | ------------------ | ---------------- | ------------------------- |
| **规则一：客户雷达抓取规则**       | 监测谁、去哪里找、找什么、多久找一次 | 目标企业、数据源、关键词     | 原始采集记录、原文证据               |
| **规则二：客户雷达展厅项目需求判定规则** | 公开信息中是否存在展厅项目需求    | 原始事件、来源级别、证据     | S1–S4 候选等级（人工核验后为最终等级）    |
| **规则三：市场部客户来源的判定规则**   | 已接触项目是否优质、是否值得跟进   | 问卷答案、沟通记录、附件     | A/B/C 等级或待补充/待核验状态        |
| **规则四：行动级映射规则**        | 销售现在应该采取什么行动       | 已确认的 A/B/C、S1–S4 | 需立即跟进 / 建议跟进 / 持续观察 / 仅沉淀 |

#### 2.4.2 画像等级总分区间


| 画像等级    | 总分区间  | 语义          |
| ------- | ----- | ----------- |
| **核心**  | ≥ 80  | 全维度至少达到高分下限 |
| **重点**  | 60–79 | 多数维度高分、其余中分 |
| **观察**  | 40–59 | 全维度至少达到中分下限 |
| **非目标** | < 40  | 存在低分维度      |


> **推导依据：** 全维度“高分下限”之和为 80，“中分下限”之和为 40。因此，以 80 为“核心”下限、40 为“观察”下限，中间划分“重点”。



#### 2.4.3 入池规则


| 画像等级    | 建议入池动作          |
| ------- | --------------- |
| 核心 / 重点 | 系统推荐进入目标客户池     |
| 观察      | 仅给出推荐，需人工评估是否纳入 |
| 非目标     | 不进入常规监测         |


> **注意：** 画像只回答“这家企业值不值得长期监测”，产出“核心/重点/观察/非目标”画像等级，决定是否进入目标客户池。画像分不进入 S1–S4 或 A/B/C 的定级评分。



## 3. 规则二：客户雷达展厅项目需求判定规则



### 3.1 判定原则

客户雷达根据公开信息，判断当前企业是否存在展厅新建、翻新或升级需求，并按照项目需求证据的强弱和推进阶段进行 100 分评分，划分为 S1–S4 四个等级。

> **核心原则：** S1–S4 判断的是“展厅项目需求证据有多强”。项目推进阶段是证据强度的重要体现，但总部建设、品牌升级等一般企业动态只有在与展厅或长期展示空间明确相关时，才进入 S1–S4 定级。

**判定流程：** 事件识别 → 展厅需求准入判断 → 需求评分 → S1–S4 定级 → 人工核验 → 销售行动级映射。

### 3.2 定级前提与限制

为避免一般企业动态因关键词或信息量较多而被误判为展厅商机，评分前需先满足以下前提和限制：

1. **所有 S 等级必须与展厅明确相关**：信息中至少应出现展厅、展馆、展示中心、体验中心，或明确的长期展示、接待、参观空间。只有总部、基地、园区建设或一般品牌动态时，不进入 S1–S4。
2. **S1 必须存在明确项目动作**：必须出现展厅招标、采购、立项、改造启动或供应商征集等明确事实。没有相关证据时，即使总分达到 75 分，最高也只能评为 S2。
3. **S2 必须存在明确项目需求**：必须明确提出展厅新建、翻新、升级或建设长期展示空间的需求或意向。仅有潜在项目触发信号时，最高只能评为 S3。
4. **主体或原文无法确认时不定级**：只有标题关键词、无法确认企业主体或原文无法访问时，进入“待核验”，不直接判为 S4。
5. **过期事件不自动推送**：项目已结束、取消或超过有效窗口时，标记为“已失效”；出现新事实后重新评分。



### 3.3 展厅需求评分维度

> **权重分配逻辑：** 展厅项目需求证据强度是定级的核心，包含从潜在信号、明确需求到立项、招采和实施的完整递进过程，因此占 85 分；信息具体程度用于判断证据是否完整、是否便于核验和跟进，占 15 分。展厅对象是否明确已作为定级前提，不再重复参与评分。


| 评分维度       | 权重        | 主要判断内容                              | 权重分配依据                            |
| ---------- | --------- | ----------------------------------- | --------------------------------- |
| 展厅项目需求证据强度 | 85 分      | 综合判断信息处于潜在信号、明确需求、具体计划、正式立项还是招采实施阶段 | 直接决定项目需求是否存在及证据强弱，是 S1–S4 定级的核心依据 |
| 信息具体程度     | 15 分      | 企业主体、展厅对象、具体动作、地点和时间是否明确            | 用于判断信息是否完整、是否便于后续核实和跟进            |
| **合计**     | **100 分** | 综合反映展厅项目需求的证据强度和信息完整度               | 需求证据为主，信息完整度为辅                    |




### 3.4 具体评分标准



#### 3.4.1 展厅项目需求证据强度（85 分）

根据公开信息反映出的展厅项目需求强度和推进阶段，选择最符合的一档计分。同一事件只计一个最高档位，不累计得分。


| 公开信息情况                                                | 得分  | 判断逻辑                         |
| ----------------------------------------------------- | --- | ---------------------------- |
| 已明确提出展厅新建、翻新或升级计划，并明确建设目标、范围或时间，但尚未正式立项               | 85  | 需求较明确，仍有较大的前期介入空间            |
| 已正式立项、通过审批、明确预算或确定建设安排，尚未确定设计或实施单位                    | 75  | 项目确定性高，处于较好的前置介入期            |
| 已明确表达展厅新建、翻新、升级或长期展示空间建设需求，但尚未形成具体计划                  | 60  | 已出现明确需求，但项目条件和启动时间尚不明确       |
| 已发布方案征集、供应商招募、招标或采购公告，且仍在有效报名或投标期内                    | 45  | 需求明确、项目真实，但介入时机较晚            |
| 企业出现新总部、基地、园区建设、周年庆、品牌焕新或数字化升级等潜在信号，且与展厅或长期展示空间存在明确关联 | 25  | 存在较强潜在机会，需要持续监测              |
| 已有展厅出现老化、空间不足、功能不匹配、搬迁或扩容等明显问题，但企业尚未明确提出改造需求          | 10  | 只有潜在信号，尚不能确认真实需求             |
| 已确定设计或实施单位、已签订合同或项目已经进入实施阶段，且未发现新增采购、分包或合作窗口          | 10  | 项目真实，但主要介入窗口已经关闭或明显收窄        |
| 项目已完成、取消、终止，或相关招采已经结束且未发现后续合作机会                       | —   | 当前不存在有效销售机会，标记为“已失效”，不再计算总分  |
| 未发现展厅项目需求或潜在项目信号                                      | —   | 不满足展厅需求定级条件，不计算总分，也不进入 S1–S4 |




#### 3.4.2 信息具体程度（15 分）


| 公开信息情况                   | 得分  |
| ------------------------ | --- |
| 企业主体、展厅对象、具体动作、地点和时间基本明确 | 15  |
| 企业主体、展厅对象和需求动作明确，但缺少部分细节 | 10  |
| 只有企业主体和展厅相关事实，具体需求尚不明确   | 5   |
| 只有关键词，无法确认具体事件           | 0   |




### 3.5 S1–S4 定级标准


| 雷达等级   | 分数区间     | 业务含义                          | 默认处理            |
| ------ | -------- | ----------------------------- | --------------- |
| **S1** | 75–100 分 | 已正式立项，或进入招采、建设及改造实施阶段         | 人工核验后需立即跟进      |
| **S2** | 50–74 分  | 已明确提出展厅新建、翻新或升级需求，但尚未进入实质推进阶段 | 人工核验后建议跟进       |
| **S3** | 25–49 分  | 存在较明显的展厅项目机会或潜在触发信号，但尚未形成明确项目 | 进入观察池，持续监测      |
| **S4** | 0–24 分   | 存在展厅相关的早期或较弱线索                | 仅沉淀，待出现新证据后重新评估 |


与展厅、展示接待空间没有明确关系的一般企业动态，不进入 S1–S4 定级，仅作为企业动态留存。

### 3.6 事件子类标签

原有的事件子类继续保留，用于雷达抓取、事件识别和评分解释，但不再单独计分或直接决定 S1–S4 等级。同一事件可以同时包含多个标签，评分时按照 3.4.1 中能够被原文证据支持的最高档位计分；潜在信号和背景动态只有在同时出现展厅相关事实时，才参与 S1–S4 定级。


| 事件方向  | 可用子类标签                         |
| ----- | ------------------------------ |
| 明确项目类 | 展厅立项/招标、升级改造、设计/实施单位征集         |
| 空间窗口类 | 新总部/基地/园区、研发/创新/客户中心、总部搬迁/办公升级 |
| 潜在信号类 | 周年庆/品牌升级、数字化升级、旧展厅老化迹象         |
| 背景动态类 | 增长/融资/获奖/参展                    |




### 3.7 人工核验

系统每次评分应保留总分、S 等级、分项得分、事件标签和原文证据。S1 和 S2 仅在人工确认企业主体、展厅对象和需求事实后，才能进入销售行动级映射和企业微信推送。

无法确认企业主体、展厅对象、原文内容或信息存在冲突时，进入“待核验”，暂不生成可推送的销售行动级；项目已经结束、取消或超过有效窗口时，标记为“已失效”，仅保留历史记录。

## 4. 规则三：市场部客户来源的判定规则

市场部客户来源，是指市场人员通过客户沟通、线上问卷、会议纪要或相关材料提报的客户信息。系统通过统一的 100 分评分机制，综合判断项目的需求真实性、落地条件、项目价值和跟进机会，并划分为 A、B、C 三类。

### 4.1 定级前提与限制

为避免仅凭总分产生明显误判，评分前需先明确以下前提和限制：

1. **核心信息缺失时不正式定级**：企业主体或新建、翻新需求状态不明确时，进入“待补充/待核验”，不直接判为 C 类。
2. **关键评分信息大量缺失时不正式定级**：需求已明确，但项目就绪度、项目价值和跟进机会中有两个及以上维度完全无法评分时，进入“待补充/待核验”，不直接判为 C 类。
3. **A 类需满足明确需求前提**：只有明确存在展厅新建或翻新计划时，才可以评为 A 类；否则即使总分达到 75 分，最高也只能评为 B 类。
4. **明确没有需求时直接判为 C 类**：客户明确暂无展厅新建或翻新计划时，直接判为 C 类，待需求发生变化后重新评分。
5. **竞品深入介入时限制等级**：竞品方案已进入深化阶段且客户明确满意时，最高评为 B 类，但不因竞品存在直接否定项目价值。
6. **信息冲突时交由人工核验**：问卷、沟通记录和附件材料之间存在关键信息冲突时，暂不自动定级或推送。



### 4.2 评分维度

> **权重分配逻辑：** 客户是否明确要做（35 分）→ 项目是否具备落地条件（30 分）→ 项目本身是否优质（20 分）→ 我们是否有机会参与（15 分）。真实需求和落地条件优先，项目价值和跟进机会作为辅助判断。


| 评分维度   | 权重        | 主要判断内容                 | 权重分配依据                             |
| ------ | --------- | ---------------------- | ---------------------------------- |
| 需求明确度  | 35 分      | 客户是否有明确的展厅新建或翻新计划      | 是商机成立的首要条件，直接决定是否存在真实展厅项目需求，因此权重最高 |
| 项目就绪度  | 30 分      | 项目的立项、预算、面积和计划完成时间是否明确 | 直接影响项目能否推进和落地，是判断项目可靠程度的核心依据       |
| 项目价值   | 20 分      | 展厅规模、企业经营规模以及场地和标杆价值   | 用于判断项目体量、客户承载能力和综合价值               |
| 跟进机会   | 15 分      | 当前对接人层级以及竞品介入程度        | 影响销售介入和成交机会，但不能替代客户的真实需求和落地条件      |
| **合计** | **100 分** | 综合反映当前项目是否优质、是否值得跟进    | 真实需求与落地条件优先，项目价值和跟进机会作为辅助判断        |




### 4.3 具体评分标准



#### 4.3.1 需求明确度（35 分）


| 客户情况               | 得分  |
| ------------------ | --- |
| 已明确新建或翻新展厅，并已形成计划  | 35  |
| 有新建或翻新意向，但计划尚未完全确定 | 22  |
| 明确暂无新建或翻新计划        | 0   |


已有展厅的面积、建设或上次翻新年份，以及新办公地点搬迁计划，作为判断需求真实性的辅助依据，不重复加分。新建和翻新需求同时存在时，按其中更明确的一项计分。

#### 4.3.2 项目就绪度（30 分）


| 子项   | 对应问卷内容                                 | 得分         |
| ---- | -------------------------------------- | ---------- |
| 立项情况 | 已正式立项 / 意向阶段，未立项 / 无立项计划               | 12 / 6 / 0 |
| 预算情况 | 有初步预算且资金已落实 / 无明确预算，需方案报批 / 暂无预算，短期不推进 | 12 / 6 / 0 |
| 实施条件 | 展厅面积和计划完成时间均明确 / 其中一项明确 / 均不明确         | 6 / 3 / 0  |


> **落地时间的处理：** 计划完成时间是否明确，纳入项目就绪度；距离落地还有多久不单独加分。时间较远不代表项目价值较低，具体时间直接作为销售安排跟进节奏的依据。



#### 4.3.3 项目价值（20 分）


| 子项      | 对应问卷内容                                                                                             | 得分                 |
| ------- | -------------------------------------------------------------------------------------------------- | ------------------ |
| 展厅规模    | 展厅面积 ≥ 500㎡ / 200–499㎡ / 100–199㎡ / ＜100㎡ / 未知                                                     | 10 / 7 / 4 / 2 / 0 |
| 企业承载能力  | 营业收入 10亿元以上 / 2–10亿元 / 5000万–2亿元 / 5000万以内；营业收入缺失时，按企业规模 1000人以上 / 200–1000人 / 50–200人 / 50人以内对应计分 | 6 / 5 / 3 / 1      |
| 客户与场地价值 | 国企/央企、上市公司或政企/园区单位，且为自有独栋/园区 / 仅满足其中一项或为外资/合资 / 其他                                                 | 4 / 2 / 0          |


企业属性为多选时不重复加分。企业规模、营业收入、企业属性和办公场地主要用于判断项目承载能力和标杆价值，不能替代明确的展厅需求。

#### 4.3.4 跟进机会（15 分）


| 子项    | 客户情况                                                                  | 得分                |
| ----- | --------------------------------------------------------------------- | ----------------- |
| 对接人层级 | 高层或项目核心决策人 / 部门层级或项目实施人员 / 其他人员 / 暂不清楚                                | 7 / 4 / 1 / 0     |
| 竞品机会  | 暂无服务商对接 / 多家对比、尚未确定或竞品仅初步沟通 / 已有服务商但客户不满意 / 竞品已深入但客户态度不明 / 竞品已深化且客户满意 | 8 / 6 / 5 / 2 / 0 |


竞品机会由问卷中的“竞争对手情况、推进阶段、客户满意情况”三个问题组合判断，不分别重复加分。

### 4.4 A/B/C 定级标准


| 客户等级    | 分数区间     | 业务含义                | 默认处理           |
| ------- | -------- | ------------------- | -------------- |
| **A 类** | 75–100 分 | 需求明确、项目条件和综合价值较好    | 优先推送和跟进        |
| **B 类** | 40–74 分  | 存在真实机会，但仍需补充信息或持续培育 | 进入商机池，建议跟进     |
| **C 类** | 0–39 分   | 当前需求较弱或暂不具备转化条件     | 仅沉淀，待情况变化后重新评估 |


> **说明：** 上述分数区间为首版建议值。上线前应结合历史客户样本验证，后续可根据实际转化情况调整，并保留历史评分标准和判定记录。



### 4.5 异常状态与重新评分

为避免增加过多辅助标签，只保留影响定级和推送的必要状态：


| 信息状态    | 含义                           | 处理方式               |
| ------- | ---------------------------- | ------------------ |
| 待补充/待核验 | 企业主体、需求状态等核心信息缺失，或不同材料之间存在冲突 | 暂不定级和推送，补充或核验后重新评分 |
| 已失效     | 项目已结束、取消或明确不再推进              | 仅保留历史记录，不进入销售推送    |


未知的非核心字段暂不计分，并在评分结果中直接显示缺失项，不再单独增加项目阶段、时间窗口或紧迫程度等标签。

当需求、立项、预算、面积、计划完成时间、决策关系或竞品进展等关键信息发生变化时，系统应使用当前生效的评分标准重新评分，并保留历史评分和调整原因。

### 4.6 评分结果展示

每次评分应向市场和销售人员展示以下内容：

- 当前总分和 A/B/C 等级；
- 各评分维度的得分；
- 支撑评分的关键事实或证据；
- 当前缺失、待确认或冲突的信息；
- 建议的下一步跟进动作。

人工可以在有充分业务依据时调整等级，但必须填写调整原因，并同时保留系统评分结果和人工调整结果。

## 5. 规则四：两个信息源映射到销售行动级的规则

销售行动级不再重新判断客户价值，只负责将已经确认的市场来源 A/B/C 等级和客户雷达 S1–S4 等级，转换为销售人员可直接理解和执行的跟进动作。

### 5.1 销售行动级定义


| 销售行动级     | 含义                        | 建议处理方式                      |
| --------- | ------------------------- | --------------------------- |
| **需立即跟进** | 已出现明确需求、采购动作或综合价值较高的项目    | 进入统一商机池，实时推送企业微信，优先分配负责人并跟进 |
| **建议跟进**  | 存在较真实的项目机会，但仍需补充信息或等待条件成熟 | 进入统一商机池，定期推送企业微信，由销售评估后跟进   |
| **持续观察**  | 目前只有较早期信号，尚未形成明确项目        | 进入统一商机池，持续监测，暂不主动打扰销售       |
| **仅沉淀**   | 当前需求证据较弱、项目暂不具备转化条件或机会已失效 | 仅保存在客户档案和历史记录中，不主动推送        |




### 5.2 两类信息源的默认映射


| 信息来源  | 来源等级 | 默认销售行动级 | 默认业务去向                   |
| ----- | ---- | ------- | ------------------------ |
| 市场部提报 | A 类  | 需立即跟进   | 进入统一商机池，实时推送企业微信         |
| 市场部提报 | B 类  | 建议跟进    | 进入统一商机池，定期推送企业微信，并突出待确认项 |
| 市场部提报 | C 类  | 仅沉淀     | 进入客户档案或历史沉淀区，不主动推送       |
| 客户雷达  | S1   | 需立即跟进   | 经人工核验后进入统一商机池，实时推送企业微信   |
| 客户雷达  | S2   | 建议跟进    | 经人工核验后进入统一商机池，定期推送企业微信   |
| 客户雷达  | S3   | 持续观察    | 进入统一商机池，持续监测，暂不主动打扰销售    |
| 客户雷达  | S4   | 仅沉淀     | 进入展厅需求线索和历史记录，不主动推送      |


市场来源为“待补充/待核验”或“已失效”时，不生成可推送的销售行动级；客户雷达信息在未完成人工核验前，也不进入销售推送。

### 5.3 多来源项目的合并规则

同一企业或项目可能同时存在市场提报和客户雷达信息。合并时按以下规则处理：

1. 两个信息源分别保留原始等级、评分或证据，不相互覆盖。
2. 两个信息源分别映射为销售行动级。
3. 项目当前行动级默认取两个来源中优先级更高的结果，优先级为：**需立即跟进 > 建议跟进 > 持续观察 > 仅沉淀**。
4. 如两个来源结论明显冲突，例如市场人员反馈暂无需求，但雷达发现明确招标，系统仍保留较高行动级，同时标记“来源信息冲突”，提醒销售优先核实。

示例：


| 市场来源    | 雷达来源 | 项目当前行动级 | 说明               |
| ------- | ---- | ------- | ---------------- |
| A 类     | S3   | 需立即跟进   | 市场已确认综合价值较高的项目需求 |
| B 类     | S1   | 需立即跟进   | 雷达已发现明确项目或采购动作   |
| C 类     | S2   | 建议跟进    | 保留雷达窗口，同时核实市场反馈  |
| 待补充/待核验 | S3   | 持续观察    | 市场信息暂不参与映射       |




### 5.4 人工调整与规则变更

- 人工可根据实际业务情况调整项目的销售行动级，但必须填写原因，并保留系统建议值和人工调整值。
- 当市场 A/B/C 等级、雷达 S1–S4 等级或核验结果发生变化时，应重新映射项目的当前行动级。
- 评分权重、分级区间、来源等级与销售行动级的对应关系，以及推送方式均可由管理人员调整。
- 新规则默认只影响后续新增或重新评估的记录；已推送、已认领或跟进中的项目不应被静默覆盖，历史结果应继续保留。
