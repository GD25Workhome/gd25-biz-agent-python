# 数字文旅商机中心可配置规则设计 v3（潜在信号优化评审稿）

> **版本说明：** 本版以用户提供的《数字文旅商机中心可配置规则设计 v3（评审稿）》为基线，修订日期为 2026 年 10 月 14 日。黄色高亮仅表示本轮新增或改写内容，未高亮部分沿用所附 v3。本轮保留原量化评分及 S1–S4 分数区间，新增 S3 内部信号核验优先级及事件阶段处理规则。“待确认配置”仍表示尚未确定的具体口径，不代表已生效规则。

### 本次主要修订

1. **S3 内部核验优先级：** 纳入用户定义的 P0–P3，分别记录信号默认优先级及按当前阶段修正后的优先级，仅影响核验、监测和展示排序，不增加评分或自动推送。
2. **前期与后期空间信号：** 增加计划建设、计划搬迁、筹备开园等前置表述；区分计划/推进与已乔迁、落成、启用、开园、投产。后者展厅状态未知时默认调整为 P2，不直接判 S4。
3. **当前阶段覆盖旧计划：** 同一搬迁、建设或开园事件更新当前阶段，旧 P0 只留历史，不再参与最高优先级选择；多个独立有效信号取最高一档，不累计加分或跨级。
4. **关闭与完成事实优先：** 同一展厅范围已招标、定单位、签约或实施仍按基础 0 分归 S4；已完成项目关闭并仅保留历史评分，不能因旧乔迁消息重新计入潜在档。
5. **日期、证据及反馈：** 分开记录计划时间、预计节点和实际发生时间，保留系统与人工优先级及修正原因；区分数据源采集优先级与信号核验优先级。
6. **保留业务与量化边界：** 雷达总分仍为 100 分，沿用 75/50/25 分界线及原基础分档；市场 A/B/C 和企业画像评分不变。旧展厅两类年限信号统一为 7 年及以上。

### 2.4 企业入池判定规则

**入池前业务检查：** 先确认主体是否属于企业、政府或园区等目标建设方，装修/装饰及展陈服务商等竞争对手不因画像得分高而进入目标客户池。集团、子公司、业主及项目实施单位应区分角色，不能将中标单位误认为需求客户。

#### 2.4.1 五维画像权重

| 画像维度    | 满分 | 高分区间  | 中分区间  | 低分区间 |
| ------- | -- | ----- | ----- | ---- |
| 业务表达复杂度 | 25 | 20–25 | 10–19 | 0–9  |
| 内容更新频率  | 20 | 16–20 | 8–15  | 0–7  |
| 预算能力    | 20 | 16–20 | 8–15  | 0–7  |
| 智能化潜力   | 20 | 16–20 | 8–15  | 0–7  |
| 标杆价值    | 15 | 12–15 | 6–11  | 0–5  |

总分 = 100（五维之和）。

**画像证据要求：** 各维度应有对应来源和事实日期。预算能力不能仅凭上市、企业规模或历史营收给高分；已发现重整、经营异常或相关财务风险时，应结合当前情况复核，不自动维持满分。未知信息标为待补充，不能伪装成确定的低分或高分；已有未知维度时，不生成确定的完整画像等级。

#### 2.4.2 画像等级总分区间

| 画像等级    | 总分区间  | 语义          |
| ------- | ----- | ----------- |
| **核心**  | ≥ 80  | 全维度至少达到高分下限 |
| **重点**  | 60–79 | 多数维度高分、其余中分 |
| **观察**  | 40–59 | 全维度至少达到中分下限 |
| **非目标** | < 40  | 存在低分维度      |

> **推导依据：** 全维度“高分下限”之和为 80，“中分下限”之和为 40。因此，以 80 为“核心”下限、40 为“观察”下限，中间划分“重点”。

#### 2.4.3 入池规则

| 画像等级    | 建议入池动作          |
| ------- | --------------- |
| 核心 / 重点 | 系统推荐进入目标客户池     |
| 观察      | 仅给出推荐，需人工评估是否纳入 |
| 非目标     | 不进入常规监测         |

> **注意：** 画像只回答“这家企业值不值得长期监测”，产出“核心/重点/观察/非目标”画像等级，决定是否进入目标客户池。画像分不进入 S1–S4 或 A/B/C 的定级评分。

## 3. 规则二：客户雷达展厅项目需求判定规则

### 3.1 判定原则

客户雷达根据公开信息及人工核验事实，判断企业、政府或园区是否存在展厅新建、翻新或升级需求，按“展厅需求及当前介入机会 85 分 + 信息完整度 15 分”计算总分，再按明确分数区间划分 S1–S4。

> **核心原则：** 当前事实决定计分档位，总分决定 S 等级。固定 S4 条件优先选择基础 0 分档，不再选择旧计划的高分档；其信息完整度最高 15 分，总分仍低于 25 分。规则约束通过分档体现，不取消量化评分，也不在评分后无依据地改变等级。

**判定流程：** 原文抓取 → AI 提取事件阶段、展厅阶段及对应证据 → 主体与业务范围检查 → 当前阶段、固定 S4 条件及已完成事实检查 → 选择唯一基础分档并加信息完整度分 → 按总分区间生成候选等级 → S3 匹配目录优先级并按当前事件阶段修正 → 人工核验/重新评分或修正优先级 → 销售行动级映射。已完成/已失效项目不生成新的有效评分。

**判定对象：** 按同一主体、展厅项目、地点及采购范围判断，不将一家企业的所有展厅需求合并为同一条线索。旧项目进入 S4，不影响该企业另一个独立展厅项目的判断。

### 3.2 定级前提与限制

1. **先判断是否属于目标业务：** 重点识别企业、政府及园区的长期展厅、展馆、展示中心等新建、翻新或升级需求。亲子乐园、展会临时展台、普通门店装修等非目标场景不进入展厅商机定级；“体验中心”等名称必须结合实际用途判断。
2. **抓取候选与真实需求分开：** 企业、政府/园区及已有展厅目录信号均可抓取，包括计划建设、计划搬迁等前置状态。核实目标主体、事件及有效时间后，可进入 25 分潜在档；原文不必出现“展厅”，也不必先证明未建展厅或旧展厅满 7 年。潜在关联标为推断；只有关键词、未经核实的猜测或非目录一般动态不自动计分。同一展厅范围的固定关闭或已完成事实优先，不能再以旧空间信号建立当前 S3 机会。
3. **S1 必须有具体计划和前期介入依据：** 已明确提出展厅新建、翻新或升级计划，并至少明确建设目标、范围或时间，当前阶段仍适合前期介入，且未命中 S4 固定条件。具体计划档和正式项目安排档分别计 85/75 分，再加信息完整度分；是否已立项不再作为 S1 的唯一门槛。
4. **S2 必须有明确需求或意向：** 已明确表达展厅新建、翻新或升级需求，但具体计划或启动安排尚未完善，且未命中 S4 固定条件。仅有周年庆、总部建设或老展厅迹象等潜在信号时，不得评为 S1 或 S2。
5. **固定 S4 条件优先选择计分档：** 对同一展厅采购范围，展厅建设本身已发布招标公告，或已确定设计/实施单位、已签约、已进入实施阶段，基础分固定为 0 分。加信息完整度分后总分为 0–15 分，按分数仍为 S4；不能再用早期计划计 75/85 分。具体采购范围按 3.4.2 区分。
6. **按计分档区分关键事实：** 明确需求/计划档应核实主体、展厅对象及影响评分的当前阶段和采购范围；潜在 25 分档应核实目标主体、目录信号事件及有效时间，具体展厅对象、是否已有展厅或展厅采购阶段可以未知，不因此统一待核验或降到 5 分。只有所用档位的关键事实无法确认、原文不可访问或存在未解决冲突时，才待核验；“未查到招标”仍不能直接等同于“尚未招标”。
7. **信息状态与等级分别记录：** “待核验”表示判断依据不足；“已失效”表示该条需求或原始事件已结束、取消或超过有效窗口。有效、仍在执行的展厅招标及实施项目按基础 0 分计为 S4，不因此自动标记已失效。已完成、取消或终止的原项目标记已失效，保留历史评分、等级及关闭依据，不新增有效评分、不进入当前 S3 观察或核验队列；历史等级仅代表当时结果，不直接改成与历史分数不一致的 S4。单条事件过期不自动关闭仍有独立有效事实支持的需求。

### 3.3 展厅需求评分维度

恢复雷达独立的 100 分量化评分。先根据当前有效事实和固定 S4 条件选择适用的基础分档，再计算信息完整度分，最后按总分区间确定 S1–S4。业务条件用于选择计分档位，不替代分数定级。

| 评分维度        | 满分        | 主要判断内容                              | 计分方式                                     |
| ----------- | --------- | ----------------------------------- | ---------------------------------------- |
| 展厅需求及当前介入机会 | 85 分      | 需求是否明确、当前推进阶段及前期介入窗口是否仍存在           | 按 3.4.1 选择唯一适用档位；固定 S4 条件优先，不能再选早期高分档    |
| 信息完整度       | 15 分      | 主体、实际展厅对象或真实信号对象、具体动作、地点和事实发生时间是否明确 | 按 3.4.4 选择 15/10/5/0 分档位，潜在信号不强求已有具体展厅对象 |
| **合计**      | **100 分** | 综合反映需求明确程度、当前介入价值及信息完整度             | **总分 = 基础分 + 信息完整度分；按 3.5 的分数区间定级**      |

证据质量单独记录来源、事实状态、缺失和冲突，不作为第三项加分。关键证据不足的线索进入待核验，不将未知事实补全后凑分。画像分和市场部 A/B/C 分均不参与雷达总分。

> **计分边界：** 已招标、已定单位、已签约或已实施的展厅项目，基础分固定为 0 分，即使信息完整度为 15 分，总分也只有 15 分，仍为 S4。0 分表示当前前期介入窗口已关闭，不表示原文不可信或项目不存在。

### 3.4 具体评分及判定标准

#### 3.4.1 展厅需求及当前介入机会（85 分）

按下表顺序执行：先检查固定 S4 条件；未命中时，再按当前有效阶段选择其他唯一适用档位。依据不足或阶段冲突时待核验，不按历史最高分或信息量选择档位。

| 当前有效事实                                                           | 基础分    | 加信息分后的总分                      | 对应等级及判断依据                                                                |
| ---------------------------------------------------------------- | ------ | ----------------------------- | ------------------------------------------------------------------------ |

**与 v2 的关键数值调整：** 明确意向由 60 分调整为 55 分，使其加满 15 分仍低于 S1 下限；弱迹象由 10 分调整为 5 分，使其加满 15 分仍低于 S3 下限；固定 S4 情况由原 10 分档改为优先执行的 0 分档，解决 10 + 15 = 25 分误升 S3 的问题。其他 85/75/45/25 分档及 85 + 15 的权重结构保留，但正式展厅招标已从原 45 分档移入固定 0 分档。

本版分值为评审稿建议配置，分值调整依据是业务边界及跨级校验，尚不代表已通过历史样本或转化数据验证。上线前按 3.8 校验，后续调整权重或分档时不得破坏固定 S4 和各类需求的分数边界。

**档位互斥：** 先命中关闭档 0 分；未关闭时，当前正式立项/审批/预算或建设安排适用 75 分，具体计划但未形成正式安排适用 85 分；两者均不满足时，已核实的前期意向征集适用 45 分，单纯明确意向适用 55 分。已有具体计划或正式安排时，不因出现“征集”字样降为 45 分。潜在依据和弱迹象分别使用 25 分和 5 分，不叠加，也不以旧阶段的高分覆盖当前阶段。

“可能存在分包或合作”不得自动解除同一项目的固定 0 分条件。确有新的独立展厅、后续新增采购或新增升级范围时，应明确新对象、新范围和新采购事实，另建需求记录并独立评分；原项目保留原评分、等级及历史证据。

| ------------------- | --------------------------------------------- | ------------------------------------------------------------------------------- |

项目标题中的“工程”“装修”“展厅”等词只能触发候选识别，不能直接决定招标类型。AI 应提取业主/采购人、项目名、采购范围、标段或采购包，以及所选设计/实施单位；不能将中标施工企业误作需求方。

**待确认配置：** 非招标方式的采购公告、方案征集及供应商招募，是否视为展厅采购窗口关闭，应按具体采购性质配置并确认。本版不将所有“征集”统一视为 S4，也不将其统一视为前期机会；性质未确认时不自动推送。

#### 3.4.3 潜在需求信号目录与筛选条件

潜在需求覆盖企业、政府/园区及已有展厅三类场景，包括潜在新建、内容更新、智能化升级、接待能力提升、招商展示和品牌展示需要。“尚未建设展厅”或“已有展厅满 7 年”不作为所有潜在线索的共同前提。

**潜在档准入：** 目标主体、目录信号事件及有效时间有可核验依据，且未发现针对本次拟评估展厅范围的固定关闭或已完成事实时，可进入 25 分基础档，并说明可能影响的展示、接待、招商、品牌表达或内容更新场景。原文不必出现“展厅”，也不必先查明已有展厅状态；潜在业务关联须标为推断，不能写成已确定的建设需求。只有关键词、未经证实的预测或关键事实冲突时，先待核验，不计算正式总分和等级。

**S 等级与核验优先级：** S1–S4 按现有总分区间判断需求明确程度及当前介入机会；P0–P3 仅用于 S3 潜在线索的人工核验、监测及展示排序，优先级依次递减。P0 不等于 S1，P3 不等于 S4。保留 25 分潜在基础档及信息完整度计分，不按信号类别、数量或优先级额外加分，不增加潜在需求专项评分。核验优先级不直接改变销售行动级或触发销售推送。

**优先级配置：** 下表为本版的默认信号核验优先级。AI 根据已提取的信号类型匹配配置，并按后文的当前阶段规则修正，不自行推测权重、成交概率或新的优先级。数据源采集优先级与信号核验优先级分别记录；高优先级信号仍须满足其来源对应的证据和核验要求。

| 同一地点及对应范围的配套展厅已完成并发布、开放或投入使用                     | 关闭该条新建机会，标记已完成/已失效，保留历史评分和证据，不新增有效评分             | 移出当前 S3 观察和优先级队列，仅沉淀；不能再次因同次乔迁或开园记录生成 25 分潜在线索                          |
| 空间事件已超配置有效窗口，且未有其他独立有效事实支持当前潜在需求                 | 该事件不再支持新增评分；按历史事实留存                              | 不参加当前优先级排序。单条事件失效不自动关闭仍有其他独立有效依据的需求                                     |

**建筑与展厅分别判断：** 大楼落成、总部乔迁、园区开园或基地投产，只说明载体或空间事件进入后期。关闭展厅机会须有同一主体、地点及展厅范围的招标、定单位、签约、实施或完成证据。无法确认是否同址、同一展厅或同一范围时，核验关联关系，不以企业名称相同直接关闭整家企业的所有机会。

**同一事件按当前阶段更新：** “计划搬迁 → 筹备搬迁 → 已乔迁”是同一事件的阶段推进。后续事实更新当前优先级，早期计划及原 P0 仅保留在历史记录，不再作为独立有效信号参加当前最高优先级选择。历史 P0 不能覆盖当前已乔迁的 P2，也不能覆盖展厅已完成或固定关闭事实。当前阶段按事实发生时间、实际范围和来源依据判断，不按网页发布时间或历史最高档位判断。

**多个信号的处理：** 同一条潜在线索可以保留多个独立信号，基础分只计一次；当前核验优先级取已核实、仍有效、已按阶段修正且适用于该线索的信号中最高的一档，P0 高于 P1、P1 高于 P2、P2 高于 P3。P1 加 P1 仍为 P1，不能按数量累计为 P0 或 S1/S2。失效、被新阶段替代、重复转载或已关闭范围的信号不参与选择。部分信号阶段未知时，仅将对应信号的优先级标为待确认，其他独立有效信号继续参与排序；只有当前全部信号均无法确定优先级时，才将整条线索单列为优先级待核验。同一旧展厅年限在两个类别中命中属于同一事实，应合并。不同地点、展厅或独立新增范围分别建立记录，不能用另一条需求的 P0 恢复已完成原项目。

**明确需求与完成事实优先：** 仅有目录信号时，按 25 分潜在档加信息完整度分，仍为 S3。出现明确展厅需求或具体计划时，按对应量化档重新判断；即使目录默认 P3，也可按事实进入 S2/S1。同一范围已命中固定关闭条件时，优先选择 0 分基础档。已完成项目按已失效留存，不把历史 S 等级及分数作为当前有效结果，也不只修改等级标签而保留不一致的当前总分。

**年限与展厅状态：** 旧展厅年限统一采用 7 年及以上，核实建成日期及近期整体翻新情况；不能仅凭首次建成年份判断当前展厅已陈旧。内容过时、AI 升级、接待压力和更新困难等独立信号，不因展厅未满 7 年而被排除。没有查到展厅资料时，状态记录为未知；不能由搜索无结果推断“未建展厅”。已搬迁或已启用但展厅状态未知时，按阶段表处理，不自动关闭或默认恢复早期优先级。

**日期与信号有效期：** 分别记录计划发布/确认时间、预计搬迁/投产/开园时间、实际发生时间、新闻发布日期及抓取时间；无法精确到日时记录日期精度和可确认区间，不补造日期。计划信号按当前仍有效的计划判断；发现实际完成、取消、延期或新安排时，更新当前阶段及核验优先级。旧新闻、回顾文章和转载不因近期被抓取而成为新的前期信号。周年和旧展厅年限按成立/建成日期及评估日期计算完整年数；只有年份且临近边界无法确认时核验。年限是持续状态，不能仅因建成新闻较早就自动判该信号过期。

**事实证据与潜在推断：** 上市、拟上市和认定应是本次可核验事件，不把既有身份或历史荣誉重复作为新信号；融资后品牌升级须核实组合事实。展示关联属于推断时明确标注。“频繁”“集中”“压力增加”“维护不及时”等须有活动记录、可比较事实或人工核验说明。低等级来源的高优先级信号仍须按来源要求核验，P0 不代表证据可信度更高。

**存量展厅与独立新需求：** 过去已建成的展厅可以出现新的内容更新、智能化或接待能力问题；有新的独立需求依据时另建候选并重新判断，保留原建设项目的关闭记录。当前升级范围本身已招标、定单位、签约或实施时，仍执行固定 0 分档。不得仅凭“升级、展示、接待”等新标签重新激活同一已完成范围。

**待确认配置：** 周年类型及“未来 1—2 年”的具体日期窗口、旧展厅年限起算口径、各类计划/推进/已启用信号的有效期，以及“频繁/集中”等统计窗口和阈值。默认类别优先级及本表阶段修正规则按版本维护；人工修正须有事实依据并保留原因。未配置统计口径的子类可先人工核验，不阻断其他独立已核实信号；不由 AI 自行补造阈值、有效期或优先级。

#### 3.4.4 信息完整度（15 分）

在可评分的事件中，根据原文或人工核验事实选择唯一档位，与基础分相加后用于 S 等级定级。明确需求记录按实际展厅对象及需求动作核验；潜在记录按真实信号对象及信号动作核验，例如总部、园区、上市或品牌事件，不强求具体展厅对象已存在，也不能补造展厅对象。不按信息篇幅、关键词数量或来源数量加分。

| 信息情况                                    | 得分 | 使用说明                                                     |
| --------------------------------------- | -- | -------------------------------------------------------- |
| 主体、实际展厅对象或真实信号对象、具体动作、地点和事实发生时间基本明确     | 15 | 信息完整；潜在信号 25 + 15 = 40 分仍为 S3；已实施项目 0 + 15 = 15 分仍为 S4   |
| 主体、实际对象和需求动作/目录信号动作明确，但缺少部分地点或时间等非核心细节  | 10 | 明确需求、具体计划及 45 分前期意向征集须达到本档；潜在事件可按实际信号信息达到本档，不表示真实展厅需求已成立 |
| 主体及所用目录信号/弱迹象已核实、有效时间可确认，但实际对象或更多细节仍待补充 | 5  | 已核实潜在事件可配合 25 分档；展厅状态未知不阻断评分。不能与要求明确需求动作的 45 分档组合        |
| 只有关键词，无法确认具体事件                          | 0  | 待核验，不计算正式总分和等级；0 分不代表已经确认无机会                             |

**关键缺失处理：** 根据所用档位判断缺失项。潜在档的主体、目录事件或有效时间不明时先待核验；具体展厅对象、既有展厅状态、预算或采购阶段未知，可以记录为待补充，不影响其他已核实目录信号计 25 分。明确需求/计划或固定关闭档仍须核实实际展厅对象、范围和阶段；低信息分不能替代这类关键事实核验。

#### 3.4.5 证据质量与当前阶段判断

1. 每项影响等级的事实都应附对应原文片段、来源链接及事实发生时间；发布日期、抓取时间与事实时间分别记录。
2. AI 保留“拟、计划、尚未、已签约、已实施、已取消”等时态及否定信息，区分明确事实、合理推断、未知和冲突；未知留空，不补造阶段、日期或需求。
3. 同一项目有多条信息时，按事实发生时间、适用采购范围和来源可信度确定当前阶段。较晚发布的回顾文章不自动覆盖较早的实际招标、签约或实施事实。
4. 不再使用“取最高分档位”或“选择最高需求证据”作为当前定级依据。旧规划只能保留在历史时间线中，不能覆盖当前已招标、定单位、签约或实施的事实。
5. 来源级别用于判断事实是否可确认或需复核，不直接增加商机等级。低等级来源、无法访问原文或相互冲突的关键事实，应交由人工核验。
6. 如出现撤销招标、项目重启或明确的新采购事实，先核实原窗口是否已结束及新范围是否独立，再重新判定或另建需求；不能只凭新增报道自动解除 S4。

### 3.5 S1–S4 定级标准

| 雷达等级   | 分数区间     | 业务含义                                                    | 默认处理            |
| ------ | -------- | ------------------------------------------------------- | --------------- |
| **S1** | 75–100 分 | 展厅新建、翻新或升级计划明确，仍有较好的前期介入空间                              | 人工核验后需立即跟进      |
| **S2** | 50–74 分  | 已出现明确展厅需求，具体计划尚待完善；包括相关前置工程已进入招采期，但展厅建设本身尚未招标、仍有参与机会的情况 | 人工核验后建议跟进       |
| **S3** | 25–49 分  | 存在展厅相关的潜在需求信号，或已有项目的参与空间有限，需持续观察                        | 进入观察池，持续监测      |
| **S4** | 0–24 分   | 展厅需求线索较弱，或现有项目暂缺可参与的合作机会，当前跟进依据不足                       | 仅沉淀，待出现新证据后重新评估 |

**招采边界：** 前置工程进入招采期是可能出现的场景，不直接决定 S2；仍须按展厅需求总分定级，且未命中 3.4.1 固定 0 分档。展厅新建、翻新或升级计划明确、总分达到 75 分时，仍为 S1；只有潜在依据、总分为 25–49 分时，为 S3。展厅建设本身已招标、已定单位、已签约或已实施的，基础分为 0 分，总分最高 15 分，属于 S4；S3 中“参与空间有限”不能覆盖这些固定条件。

**总分公式与排序：** 雷达总分 = 展厅需求及当前介入机会基础分 + 信息完整度分，S1–S4 定级仍严格按总分区间执行。S3 潜在线索先按当前有效信号核验优先级 P0 → P1 → P2 → P3 排序，同优先级内再按总分从高到低、当前有效事实时间从近到远排序；预计节点用于安排核验节奏，不能由 AI 补造。仅当当前没有任何可确定优先级的有效信号时，整条线索单列为优先级待核验，不默认归最高或最低档；部分信号阶段未知不阻断其他独立有效信号参与排序。其他等级沿用同等级总分排序；不增加新的排序分。

**执行优先级：** 先核实主体、业务范围和关键事实；存在未解决冲突时待核验。事实充分时先检查固定 0 分档，再按当前有效阶段选唯一基础分档、计算信息分和总分。信息完整度不得使明确意向跨入 S1、潜在信号跨入 S2、弱迹象跨入 S3 或固定关闭项目跨入 S3；具体边界见 3.4.1。

如果总分对应的等级与原文事实不符，应检查是否选错基础档或信息档，必要时转待核验；不得保留不一致总分、仅手工替换等级。既无目标展厅事实，也无符合条件的潜在信号时，只留存为企业动态，不计分，也不勉强归入 S4。

### 3.6 事件子类标签

原有事件子类用于抓取、识别和解释，不单独计分，也不直接决定 S 等级。同一事件可以包含多个标签，但必须按当前有效事实及采购范围定级，不能按历史信息中的最高档位判断。

| 事件方向       | 可用子类标签                                                                                                                               |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 明确项目类      | 展厅计划/立项、展厅招标、升级改造、设计/实施单位征集                                                                                                          |
| 空间窗口类      | 新总部/基地/园区计划及建设推进、计划搬迁/搬迁筹备、已乔迁/落成/启用、预计/已投产或开园、研发/创新/客户中心、前置工程招投标；事件阶段与展厅阶段分别记录                                                      |
| 企业潜在信号类    | 新总部计划建设/建设推进/计划搬迁/搬迁筹备/已搬迁或落成，新工厂/基地/园区计划建设或投产/已投产，上市/拟上市，融资后品牌升级，战略发布，周年庆，重大客户接待，政府调研频繁，新产品发布，AI/数字化转型，企业旧展厅建成 7 年及以上，专精特新/独角兽/链主认定 |
| 园区/政府潜在信号类 | 新园区计划开园/开园筹备/已开园，招商中心计划建设/建设推进/已启用，新产业规划发布，产业大会，产业基金成立，城市更新，政府考察，招商攻坚，频繁招商发布，年度产业成果展示，企业集中签约                                         |
| 已有展厅潜在信号类  | 旧展厅建成 7 年及以上，内容过时，领导提出 AI 升级，接待压力增加，原供应商维护不及时，数字内容更新困难                                                                               |
| 背景动态类      | 一般增长、未伴随品牌升级的普通融资、非目录普通获奖、一般参展；不因背景词直接计入潜在档                                                                                          |

### 3.7 人工核验、展示与反馈

系统每次评分应保留总分、基础分、信息完整度分、S 等级、计分档位、事件阶段与展厅阶段、计划/预计/实际时间、标签、证据、缺失/冲突项及规则版本。S3 另记录目录默认优先级、按当前阶段修正的系统候选优先级、人工最终优先级、对应有效信号及修正原因；数据源采集优先级单独记录。核验前后保留系统与人工结果，不只保留最终等级或优先级。

S1 和 S2 仅在人工确认主体、展厅对象、需求事实、当前阶段及是否命中 S4 条件后，才能进入销售行动级映射和企业微信推送。S4 仅沉淀；核心事实不清时保持待核验，不通过人为调低信息分替代核验。

运营人员补充的信息应分别记录“补充/修正了哪些事实”和“为何调整等级”，并同时保留系统原结果与人工结果。人工调整须先修正事实及对应评分档位，再重新计算总分和 S 等级，并保留调整前后分项。仍命中固定 S4 条件的原项目，不能只写调整理由就升级，须先核实并修正相关事实、采购范围或新需求记录。

补充事实、人工调整原因及最终核验结果应同步到商机中心供查看。事实变化时重新选择适用计分档位、计算总分和等级，或更新 S3 当前核验优先级，再更新销售行动映射；同次事件的新阶段替代旧阶段参与当前排序，保留完整变更记录。仅 P 优先级变化不自动改变销售行动级。已完成项目仅保留历史评分并移出当前队列，不用新增空间标签重新激活。

经审核的人工核验记录用于历史样本验证、词表优化、AI 事实提取要求及规则调整。不能将每条人工备注直接当作真实标签，也不承诺数据积累后自动训练或必然提升准确率。

S3 运营视图展示当前核验优先级、事件阶段、预计/实际节点、原文事实和待补充项，按 3.5 排序。仅有高优先级潜在信号时仍持续观察；人工核验发现明确需求后，先修正事实并按对应档位重新评分，再按 S1/S2 规则处理。人工调整优先级须有事件、阶段或业务关联依据并填写原因，保留系统值、人工值及规则版本；不得仅用优先级调整绕过固定 S4 或完成关闭规则。

### 3.8 规则样本验证

上线前及每次规则版本变更时，使用人工确认样本检查分项、总分、等级、当前事件阶段、S3 核验优先级及推送结果；穷举合法信息分组合，验证加分后仍符合业务边界，同时检查阶段更新、重复信号、完成关闭和排序。下表为规则期望，不代表现有系统已实现。

| 样本情况                                      | 预期处理                                                  |
| ----------------------------------------- | ----------------------------------------------------- |
| 展厅已实施，主体、地点、动作及时间全部明确                     | 基础 0 + 信息 15 = **15 分，S4**；不主动推送                      |
| 展厅招标已发布，仍在报名期或尚未开标，信息完整                   | 基础 0 + 信息 15 = **15 分，S4**；不进入 S1/S2                  |
| 前置建筑工程已开标，展厅有具体前期计划，尚未正式安排，信息完整           | 展厅基础 85 + 信息 15 = **100 分，S1**；不因前置工程开标按关闭档计分         |
| 前置工程有已核实的展厅预留或规划依据，满足潜在条件，但无明确项目需求，信息分 5  | 基础 25 + 信息 5 = **30 分，S3**；不能凭工程规模升为 S1               |
| 新总部建设事实及主体已核实，原文没有展厅字样，展厅状态未知             | 命中空间节点：25 + 信息 5/10/15 = **30/35/40 分，S3**；不因展厅状态未知排除 |
| 旧消息为展厅规划，新事实已确定实施单位，信息完整                  | 选当前关闭档：0 + 15 = **15 分，S4**；不能用旧 85 分档                |
| 同一家企业旧展厅已实施，另有独立新展厅计划                     | 旧项目按 0 分基础档计 S4；新对象另建记录并独立评分                          |
| 主体已公开周年庆活动，周年及时间事实已核实，展厅状态未知              | 可进入 25 分潜在档，不要求未建或旧展厅满 7 年；仅靠不准确日期猜测周年时先待核验           |
| 未找到展厅资料，但企业上市/拟上市等目录事件已经核实                | 展厅状态记未知；按已核实信号计 25 分，不补造未建事实，也不因此阻断 S3                |
| 展厅首次建成已满 7 年，但近期有整体翻新事实                   | 核验年限口径，不只凭首次年份成立“年限更新”；其他独立目录信号仍可正常评分                 |
| 招标仅有标题，采购范围不清，或原文存在关键冲突                   | 待核验，不自动判 S4 或推送                                       |
| 同一展厅范围雷达已确认招标，市场端仍保留旧 A 类                 | 雷达按 0 分基础档计算 S4；原始市场等级保留，当前行动级仅沉淀                     |
| 仅有明确意向，尚未形成具体计划，信息完整                      | 55 + 15 = **70 分，S2**；不能使用原 60 + 15 误升 S1             |
| 非正式招标的前期意向征集性质已核实，未满足具体计划档，信息明确           | 45 + 10/15 = **55/60 分，S2**；信息不符合明确需求时先待核验            |
| 展厅相关弱迹象可核实，但未达到潜在需求条件，信息完整                | 5 + 15 = **20 分，S4**；已核实三类目录事件不能因展厅状态未知降至此档           |
| 企业发布新产品、获评链主或园区集中签约，事件与主体均已核实             | 命中任一目录信号：基础 **25 分**，不需要先公开展厅建设需求                     |
| 展厅未满 7 年，但有核实的内容过时或数字内容更新困难事实，尚无明确改造需求    | 可按独立问题信号计 **25 分，S3**；7 年仅限制年限筛选                      |
| 企业融资后品牌升级、战略发布及重大接待同时出现                   | 多个信号基础分仍只计 **25 分**，不累计成 75 分或 S1                     |
| 领导已明确提出具体展厅 AI 升级计划，目标/范围/时间有依据且窗口仍适合前期介入 | 按明确计划对应 **75/85 分基础档**评分，可为 S1；不强制降到潜在 25 分档          |
| 同一已实施展厅的旧报道重复提及“升级、接待”等词，未有新的独立需求事实       | 不重新套潜在 25 分档，仍按当前关闭事实计 **0 分基础档，S4**                  |
| 园区公众号频繁招商只来自同一内容反复转载，无法核实独立招商事件或频率        | 去重并核验，不能凭转载次数确认频繁信号；其他独立成立信号另行判断                      |

**本轮新增的优先级与阶段校验样本：**

| 样本情况                               | 预期处理                                              |
| ---------------------------------- | ------------------------------------------------- |
| 已核实计划搬迁新总部，原文没有展厅字样，信息分为 5/10/15   | 基础 25 + 信息 5/10/15 = 30/35/40 分，S3-P0；不直接升为 S1/S2 |
| 总部已乔迁，展厅状态未知，空间事件仍有效               | 按潜在档为 S3，当前核验优先级 P2；不继续套早期 P0，不直接判 S4             |
| 同一次总部搬迁，旧消息是计划 P0，新事实是已乔迁，展厅状态未知   | 当前阶段按已乔迁更新为 P2；旧 P0 留历史，不参与当前最高优先级选择              |
| 总部已乔迁，且同址对应配套展厅已完成并发布/开放           | 关闭原新建机会，记录已完成/已失效，保留历史评分，不新增 25 分潜在线索或继续 S3 核验排序  |
| 大楼主体施工或已落成，但尚无同一展厅的招标/实施/完成依据      | 分别判断建筑与展厅阶段；不能凭建筑施工或落成直接执行展厅固定 S4                 |
| 同一展厅已确定实施单位，另有同次搬迁的旧计划 P0          | 基础 0 + 合法信息分，仍为 S4；不参与 S3 优先级排序，旧 P0 不能解除关闭条件     |
| 计划搬迁 P0 线索为 30 分，新产品发布 P2 线索为 40 分 | 两条均为 S3，先核验 P0；不能只按信息完整度导致的总分排序                   |
| 多个独立有效 P1 信号同时出现，信息完整              | 基础仍为 25，25 + 15 = 40 分，S3-P1；不累计为 P0 或 S1/S2      |
| 旧 P0 事件已失效，另有独立有效 P1 信号支持当前线索      | 失效 P0 不参与选择，按有效 P1 确定当前优先级；不因单条失效关闭整个需求           |
| 城市更新项目处于计划阶段，尚无明确展厅需求              | 符合目录准入时仍为 S3-P2；不因“计划”一词套用空间类别的 P0                |
| 默认 P3 的领导 AI 升级信号，经核验已有明确展厅升级意向或计划 | 按明确意向/计划对应基础档重新评分，可为 S2/S1；退出 S3 优先级队列，不受 P3 限制   |
| P0 周年庆信号来自公众号等 P2 数据源              | 两项优先级分别记录；先按来源要求核验，P0 不自动代表证据可靠或可销售推送             |
| 旧展厅建成 6 年，仅命中年限条件，未有其他独立信号         | 不满足 7 年及以上的年限准入，不仅凭年限生成 S3-P1；其他独立目录事实另行判断        |
| 同一旧展厅年限分别命中企业旧展厅、已有展厅年限更新          | 合并为同一事实，只计一次 25 分基础档，优先级仍为 P1                     |
| 最近抓取到去年已乔迁的回顾文章，没有新的前期计划           | 按实际乔迁时间、当前阶段及有效期判断，不用抓取时间重新生成近期 P0                |
| 同条线索已有独立有效 P1，另一空间信号阶段尚未知          | 继续按 P1 排序，仅将未知阶段的信号列入待核验；不移出整条有效 S3 线索            |
| 同一企业原总部展厅已完成，另有不同地点或独立范围的新展厅计划     | 原项目关闭并留历史；新需求另建记录，按自身事实评分，不关闭整家企业                 |

## 4. 规则三：市场部客户来源的判定规则

市场部客户来源，是指市场人员通过客户沟通、线上问卷、会议纪要或相关材料提报的客户信息。系统通过统一的 100 分评分机制，综合判断项目的需求真实性、落地条件、项目价值和跟进机会，并划分为 A、B、C 三类。

### 4.1 定级前提与限制

为避免仅凭总分产生明显误判，评分前需先明确以下前提和限制：

1. **核心信息缺失时不正式定级**：企业主体或新建、翻新需求状态不明确时，进入“待补充/待核验”，不直接判为 C 类。
2. **关键评分信息大量缺失时不正式定级**：需求已明确，但项目就绪度、项目价值和跟进机会中有两个及以上维度完全无法评分时，进入“待补充/待核验”，不直接判为 C 类。
3. **A 类需满足明确需求前提**：只有明确存在展厅新建或翻新计划时，才可以评为 A 类；否则即使总分达到 75 分，最高也只能评为 B 类。
4. **明确没有需求时直接判为 C 类**：客户明确暂无展厅新建或翻新计划时，直接判为 C 类，待需求发生变化后重新评分。
5. **竞品深入介入时限制等级**：竞品方案已进入深化阶段且客户明确满意时，最高评为 B 类，但不因竞品存在直接否定项目价值。
6. **信息冲突时交由人工核验**：问卷、沟通记录和附件材料之间存在关键信息冲突时，暂不自动定级或推送。

### 4.2 评分维度

> **权重分配逻辑：** 客户是否明确要做（35 分）→ 项目是否具备落地条件（30 分）→ 项目本身是否优质（20 分）→ 我们是否有机会参与（15 分）。真实需求和落地条件优先，项目价值和跟进机会作为辅助判断。

| 评分维度   | 权重        | 主要判断内容                 | 权重分配依据                             |
| ------ | --------- | ---------------------- | ---------------------------------- |
| 需求明确度  | 35 分      | 客户是否有明确的展厅新建或翻新计划      | 是商机成立的首要条件，直接决定是否存在真实展厅项目需求，因此权重最高 |
| 项目就绪度  | 30 分      | 项目的立项、预算、面积和计划完成时间是否明确 | 直接影响项目能否推进和落地，是判断项目可靠程度的核心依据       |
| 项目价值   | 20 分      | 展厅规模、企业经营规模以及场地和标杆价值   | 用于判断项目体量、客户承载能力和综合价值               |
| 跟进机会   | 15 分      | 当前对接人层级以及竞品介入程度        | 影响销售介入和成交机会，但不能替代客户的真实需求和落地条件      |
| **合计** | **100 分** | 综合反映当前项目是否优质、是否值得跟进    | 真实需求与落地条件优先，项目价值和跟进机会作为辅助判断        |

### 4.3 具体评分标准

#### 4.3.1 需求明确度（35 分）

| 客户情况               | 得分 |
| ------------------ | -- |
| 已明确新建或翻新展厅，并已形成计划  | 35 |
| 有新建或翻新意向，但计划尚未完全确定 | 22 |
| 明确暂无新建或翻新计划        | 0  |

已有展厅的面积、建设或上次翻新年份，以及新办公地点搬迁计划，作为判断需求真实性的辅助依据，不重复加分。新建和翻新需求同时存在时，按其中更明确的一项计分。

#### 4.3.2 项目就绪度（30 分）

| 子项   | 对应问卷内容                                 | 得分         |
| ---- | -------------------------------------- | ---------- |
| 立项情况 | 已正式立项 / 意向阶段，未立项 / 无立项计划               | 12 / 6 / 0 |
| 预算情况 | 有初步预算且资金已落实 / 无明确预算，需方案报批 / 暂无预算，短期不推进 | 12 / 6 / 0 |
| 实施条件 | 展厅面积和计划完成时间均明确 / 其中一项明确 / 均不明确         | 6 / 3 / 0  |

> **落地时间的处理：** 计划完成时间是否明确，纳入项目就绪度；距离落地还有多久不单独加分。时间较远不代表项目价值较低，具体时间直接作为销售安排跟进节奏的依据。

#### 4.3.3 项目价值（20 分）

| 子项      | 对应问卷内容                                                                                             | 得分                 |
| ------- | -------------------------------------------------------------------------------------------------- | ------------------ |
| 展厅规模    | 展厅面积 ≥ 500㎡ / 200–499㎡ / 100–199㎡ / ＜100㎡ / 未知                                                     | 10 / 7 / 4 / 2 / 0 |
| 企业承载能力  | 营业收入 10亿元以上 / 2–10亿元 / 5000万–2亿元 / 5000万以内；营业收入缺失时，按企业规模 1000人以上 / 200–1000人 / 50–200人 / 50人以内对应计分 | 6 / 5 / 3 / 1      |
| 客户与场地价值 | 国企/央企、上市公司或政企/园区单位，且为自有独栋/园区 / 仅满足其中一项或为外资/合资 / 其他                                                 | 4 / 2 / 0          |

企业属性为多选时不重复加分。企业规模、营业收入、企业属性和办公场地主要用于判断项目承载能力和标杆价值，不能替代明确的展厅需求。

#### 4.3.4 跟进机会（15 分）

| 子项    | 客户情况                                                                  | 得分                |
| ----- | --------------------------------------------------------------------- | ----------------- |
| 对接人层级 | 高层或项目核心决策人 / 部门层级或项目实施人员 / 其他人员 / 暂不清楚                                | 7 / 4 / 1 / 0     |
| 竞品机会  | 暂无服务商对接 / 多家对比、尚未确定或竞品仅初步沟通 / 已有服务商但客户不满意 / 竞品已深入但客户态度不明 / 竞品已深化且客户满意 | 8 / 6 / 5 / 2 / 0 |

竞品机会由问卷中的“竞争对手情况、推进阶段、客户满意情况”三个问题组合判断，不分别重复加分。

### 4.4 A/B/C 定级标准

| 客户等级    | 分数区间     | 业务含义                | 默认处理           |
| ------- | -------- | ------------------- | -------------- |
| **A 类** | 75–100 分 | 需求明确、项目条件和综合价值较好    | 优先推送和跟进        |
| **B 类** | 40–74 分  | 存在真实机会，但仍需补充信息或持续培育 | 进入商机池，建议跟进     |
| **C 类** | 0–39 分   | 当前需求较弱或暂不具备转化条件     | 仅沉淀，待情况变化后重新评估 |

> **说明：** 上述分数区间为首版建议值。上线前应结合历史客户样本验证，后续可根据实际转化情况调整，并保留历史评分标准和判定记录。

### 4.5 异常状态与重新评分

为避免增加过多辅助标签，只保留影响定级和推送的必要状态：

| 信息状态    | 含义                           | 处理方式               |
| ------- | ---------------------------- | ------------------ |
| 待补充/待核验 | 企业主体、需求状态等核心信息缺失，或不同材料之间存在冲突 | 暂不定级和推送，补充或核验后重新评分 |
| 已失效     | 项目已结束、取消或明确不再推进              | 仅保留历史记录，不进入销售推送    |

未知的非核心字段暂不计分，并在评分结果中直接显示缺失项，不再单独增加项目阶段、时间窗口或紧迫程度等标签。

当需求、立项、预算、面积、计划完成时间、决策关系或竞品进展等关键信息发生变化时，系统应使用当前生效的评分标准重新评分，并保留历史评分和调整原因。

### 4.6 评分结果展示

每次评分应向市场和销售人员展示以下内容：

- 当前总分和 A/B/C 等级；
- 各评分维度的得分；
- 支撑评分的关键事实或证据；
- 当前缺失、待确认或冲突的信息；
- 建议的下一步跟进动作。

人工可以在有充分业务依据时调整等级，但必须填写调整原因，并同时保留系统评分结果和人工调整结果。

## 5. 规则四：两个信息源映射到销售行动级的规则

销售行动级不重新计算客户价值，将已确认的市场来源 A/B/C 等级和雷达 S1–S4 等级转换为跟进动作；映射前先核实是否为同一项目和采购范围，以及是否存在最新有效的招标、定单位、签约或实施事实。

### 5.1 销售行动级定义

| 销售行动级     | 含义                                | 建议处理方式                      |
| --------- | --------------------------------- | --------------------------- |
| **需立即跟进** | 已确认的明确需求或较高价值项目，且当前仍存在符合业务策略的跟进窗口 | 进入统一商机池，实时推送企业微信，优先分配负责人并跟进 |
| **建议跟进**  | 存在较真实的项目机会，但仍需补充信息或等待条件成熟         | 进入统一商机池，定期推送企业微信，由销售评估后跟进   |
| **持续观察**  | 目前只有较早期信号，尚未形成明确项目                | 进入统一商机池，持续监测，暂不主动打扰销售       |
| **仅沉淀**   | 当前需求证据较弱、项目暂不具备转化条件或机会已失效         | 仅保存在客户档案和历史记录中，不主动推送        |

### 5.2 两类信息源的默认映射

| 信息来源  | 来源等级 | 默认销售行动级 | 默认业务去向                                      |
| ----- | ---- | ------- | ------------------------------------------- |
| 市场部提报 | A 类  | 需立即跟进   | 进入统一商机池，实时推送企业微信                            |
| 市场部提报 | B 类  | 建议跟进    | 进入统一商机池，定期推送企业微信，并突出待确认项                    |
| 市场部提报 | C 类  | 仅沉淀     | 进入客户档案或历史沉淀区，不主动推送                          |
| 客户雷达  | S1   | 需立即跟进   | 经人工核验后进入统一商机池，实时推送企业微信                      |
| 客户雷达  | S2   | 建议跟进    | 经人工核验后进入统一商机池，定期推送企业微信                      |
| 客户雷达  | S3   | 持续观察    | 进入统一商机池，按当前信号核验优先级安排人工核验和监测；P0–P3 不直接触发销售推送 |
| 客户雷达  | S4   | 仅沉淀     | 进入展厅需求线索和历史记录，不主动推送                         |

上表适用于不存在已确认关闭事实的独立有效需求。任一来源记录为“待补充/待核验”或“已失效”时，该记录不参与新增主动推送映射，不能继续使用其历史等级。雷达 S1/S2 未完成人工核验前不推送，S3 持续观察，S4 仅沉淀。项目当前已确认完成、取消或终止时，统一行动级仅沉淀；仅原始事件过期时，不能据此关闭仍有其他独立有效事实支持的需求。出现同一范围的关闭或冲突事实时，按 5.3 优先处理。

### 5.3 多来源项目的合并规则

同一企业可能存在多个展厅需求。只有确认属于同一展厅项目及采购范围时，才合并为同一机会；不同地点、不同展厅或独立新增范围分别判断，不能把整家企业统一归为 S4。

1. **保留来源原始记录：** 两个信息源分别保留原等级、评分、证据、核验时间及人工调整记录，不相互覆盖。
2. **先核实当前有效事实：** 按事实发生时间和实际项目范围判断，不简单按网页发布日期、录入时间或原始等级高低选择结论。
3. **确认关闭事实时优先沉淀：** 同一展厅范围已确认招标、定单位、签约或实施时，项目当前行动级为“仅沉淀”，暂停新的主动推送；已确认完成、取消或终止的需求同样仅沉淀。旧市场 A/B 类不得重新提高行动级。已推送或跟进记录保留，并展示事实变化及处理原因；仅某一原始事件过期，不自动关闭有其他独立有效事实支持的项目需求。
4. **冲突未解决时先核验：** 新旧材料无法确定是否为同一范围，或关于需求、采购和实施状态的关键事实冲突时，标记“来源信息冲突”，暂不生成新的主动推送，待人工核实后重新映射。只有候选、尚未确认的关闭信息，不自动覆盖已确认事实。
5. **其余有效需求再取较高行动级：** 不存在固定关闭事实和未解决关键冲突时，两个来源分别映射后取较高行动级：**需立即跟进 > 建议跟进 > 持续观察 > 仅沉淀**。
6. **新增独立需求单独评估：** 新展厅、后续独立采购或新增升级范围有明确事实时，可另建需求重新判断；不能用新范围的需求改变已关闭原范围的历史结论。

示例：

| 市场来源         | 雷达及当前事实              | 项目当前行动级      | 说明                   |
| ------------ | -------------------- | ------------ | -------------------- |
| A 类          | S3，未发现关闭事实及关键冲突      | 需立即跟进        | 市场已确认明确且较有价值的项目需求    |
| B 类          | S1，双方事实一致且窗口有效       | 需立即跟进        | 雷达发现具体前期计划，仍可介入      |
| 旧 A/B 类      | 同一范围已确认展厅招标、签约或实施，S4 | 仅沉淀          | 最新有效的固定条件优先，保留来源原始等级 |
| C 类，明确反馈暂无需求 | S2，需求事实与市场反馈冲突       | 待核验，暂不新增主动推送 | 先核实范围和事实先后，再决定行动级    |
| 待补充/待核验      | 已核实的 S3 潜在依据，无关键冲突   | 持续观察         | 不完整市场信息不参与提高行动级      |
| 原项目已关闭       | 另有独立新展厅需求            | 分别映射         | 原项目仅沉淀，新需求按自身事实评估    |

### 5.4 人工调整与规则变更

- 人工可依据已核验事实调整行动级，必须填写原因并保留系统值及人工值。同一范围仍命中固定 S4 条件时，不得仅凭备注重新升级；须核实原事实已变化，或明确新的独立需求范围。
- 当来源等级、当前项目阶段、采购范围或核验事实变化时，重新执行合并判断与行动级映射；核验补充信息、调整原因和最终结果应同步商机中心。
- 画像及市场评分、雷达基础分档和信息分、S1–S4 区间、潜在信号目录及有效期、默认核验优先级、适用类别的阶段修正规则、S3 排序、行动级和推送方式，由管理人员按版本维护。变更须检查评分边界、优先级映射、阶段更新和完成关闭样本；信号优先级不加入总分。固定 S4 的基础 0 分规则变更须明确审核，不能靠优先级、加权或默认映射绕过。
- 新规则默认影响后续新增或重新评估的记录；历史重评范围需明确。已推送、已认领或跟进项目保留原记录，因最新关闭事实改变当前行动建议时，显示新旧值、事实依据、时间及规则版本，不静默覆盖历史。
