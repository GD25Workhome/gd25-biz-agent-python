## 1. 运行配置

### 1.1 必配

| 变量 | 用途 |
|---|---|
| `HUAYUAN_API_KEY` | 华院 LLM 网关（`provider: huayuan`） |
| `DEEPSEEK_SEARCH_KEY` | 规则二 v3 检索链（Search / Fetch） |
| `DEEPSEEK_API_KEY` | 可选回退：未配 `DEEPSEEK_SEARCH_KEY` 时使用 |
| `EXHIBITION_MYSQL_HOST` | exhibition MySQL 主机 |
| `EXHIBITION_MYSQL_PORT` | 端口，默认 3306 |
| `EXHIBITION_MYSQL_USER` | 用户名 |
| `EXHIBITION_MYSQL_PASSWORD` | 密码 |
| `EXHIBITION_MYSQL_DB` | 库名（`unidt_exhibition`） |

### 1.2 Worker

| 变量 | 默认 | 说明 |
|---|---:|---|
| `RADAR_SCORE_WORKER_IN_APP` | `false` | `true` 时 FastAPI 进程内跑 event worker |
| `RADAR_SCORE_EVENT_CONCURRENCY` | `2` | 并发 event 任务数 |
| `RADAR_SCORE_POLL_INTERVAL_SEC` | `15` | 轮询间隔 |
| `RADAR_SCORE_STALE_TIMEOUT_SEC` | `2400` | RUNNING 超时回收 |
| `RADAR_SCORE_SHUTDOWN_WAIT_SEC` | `30` | 停止时等待在途任务 |
| `RADAR_SCORE_MAX_RETRY` | `3` | 可重试错误上限 |
| `RADAR_TENANT_ID` | 空 | 可选租户过滤 |

### 1.3 可选

| 变量 | 用途 |
|---|---|
| `DEEPSEEK_SEARCH_BASE_URL` | 默认 `https://api.deepseek.com` |
| `DEEPSEEK_SEARCH_TIMEOUT_SECONDS` | 默认 30 |
| `EXHIBITION_MYSQL_CHARSET` | 默认 `utf8mb4` |
| `EXHIBITION_MYSQL_CONNECT_TIMEOUT` | 默认 10 |
| `LANGFUSE_ENABLED` / `LANGFUSE_PUBLIC_KEY` / `LANGFUSE_SECRET_KEY` / `LANGFUSE_BASE_URL` | 可观测性；不装 `langfuse` 时自动降级 |

样例：`.env.example`。发布页字段说明：`huaYuanTestDeploy/环境变量.md`、`huaYuanTestDeploy/环境变量所有字段说明.md`。

## 2. 模型 Provider

文件：`config/model_providers.yaml`

```yaml
providers:
  - provider: "huayuan"
    api_key: "${HUAYUAN_API_KEY}"
    base_url: "https://ai-api.unidtai.com/openapi/llm/compatible-mode/v1"
    default_model: "deepseek/deepseek-v4.1-flash"
```

- 只有 `huayuan` 一个 provider；
- flow 的 react / auditor 节点都走它；
- 不读 OpenAI / 豆包 / DeepSeek LLM provider 配置。

## 3. 依赖

`requirements-huayuan.txt` 直接依赖：

```text
fastapi
uvicorn
langgraph
langchain
langchain-core
langchain-openai
pydantic
pydantic-settings
python-dotenv
httpx
pyyaml
simpleeval
pymysql
```

可选：

- `cryptography`：exhibition MySQL 使用 `caching_sha2_password` 且 PyMySQL 需要 RSA 时取消注释；
- `uvicorn[standard]`：需要 uvloop / httptools 时替换 `uvicorn`。

不安装 LLM CLI、抓取、向量库、网页解析类包；镜像内不应出现这些依赖。

## 4. Dockerfile

文件：`Dockerfile`

```text
python:3.11-slim
  + 非 root 用户 app
  + COPY --chown=app:app requirements-huayuan.txt
  + pip install --no-cache-dir
  + COPY --chown=app:app backend/ config/ radar_score/
  + USER app
  + HEALTHCHECK GET /health
  + CMD uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

关键约束：

- 不安装 Node / LLM CLI；
- 无 apt 安装段（基础镜像已带 ca-certificates）；
- `pip --no-cache-dir`，避免 `/app/.cache/pip`；
- `COPY --chown`，避免 `chown -R /app` 的 overlay 复制层；
- 只 COPY 规则二运行闭包，不 COPY 已删除的抓取 / 知识库树。

## 5. 发布脚本

文件：`huaYuanTestDeploy/push-huayuan-agent.sh`

```bash
# 只构建，不推送
PUSH=0 ./huaYuanTestDeploy/push-huayuan-agent.sh

# 构建 + 推送 TCR
./huaYuanTestDeploy/push-huayuan-agent.sh
```

行为：

- 默认平台 `linux/amd64`；`BUILD_MAC=1` 额外打本机 `:local`；
- 构建后在镜像内执行：
  - `python -c "import backend.main, radar_score"`
  - `pip check`
- 打印未压缩镜像体积；超过 `SIZE_WARN_MB`（默认 500）告警；
- `PUSH=1` 时自动 TCR 登录、推送、清理本镜像历史 tag；
- `SMOKE=0` 可跳过烟测（不推荐）。

镜像名：`unidt-exhibition-opportunity-py-agent`。

## 8. 已知限制

- **Java 跨仓**：画像 / chat / 新闻抓取调用方需在 exhibition 侧停用；本服务只保留 `/radar-event-score`。
- **TCR 部署**：本地已构建，尚未推送 / 部署；发布时保留上一 tag 供回滚。
- **MySQL 认证**：若目标库使用 `caching_sha2_password` 且 PyMySQL 报 RSA 相关错误，补 `cryptography`。
- **Docker `--env-file`**：`.env` 中带双引号的值会被原样带进容器，可能导致网关 401；K8s Secret 不受影响。
- **知识库字段**：`context.knowledge` 仍可被请求携带，但 v3 工具链不做向量召回；不要依赖它产生证据。
