### 针对你的场景（上市企业展厅需求挖掘）的具体建议

你的场景有几个关键需求：
1. **中文招投标公告**（政府采购网、公共资源交易中心）
2. **上市公司公告**（巨潮资讯、上交所/深交所公告）
3. **企业新闻/动态**（东方财富、同花顺、公司新闻稿）
4. **网页正文提取**（验证摘要中的线索）

基于这些需求，我的推荐是**组合方案**而非单一工具：

#### 推荐组合：博查 AI + Tavily + Firecrawl

**博查 AI（主搜索）**
- 中文内容收录深度优于 Google/Bing，国内直连稳定
- 返回结构化结果 + AI 摘要
- 适合作为你的"第一轮广撒网"搜索引擎
- 封装示例：
```python
from langchain_core.tools import tool

@tool
def bocha_search(query: str) -> str:
    """中文网页搜索，适合检索国内企业公告、招标信息、新闻动态。"""
    # 调用博查 API
    resp = requests.post("https://api.bochaai.com/v1/web-search",
        headers={"Authorization": f"Bearer {API_KEY}"},
        json={"query": query, "count": 10})
    return format_results(resp.json())
```

**Tavily（深度验证 + 正文提取）**
- 搜索+正文提取一体化，省去你单独写 extract 工具
- 英文信源覆盖好，适合查海外上市企业或跨国公司动态
- LangChain 原生支持，集成最顺滑
```python
from langchain_tavily import TavilySearch
tavily = TavilySearch(max_results=5, search_depth="advanced")
```

**Firecrawl（兜底抓取）**
- 当博查/Tavily 返回的摘要不够用，需要深度抓取正文时
- 支持动态页面（JS 渲染的招投标网站经常需要）
- 每月 1000 credits 免费额度

### 如果只想换一个工具

如果不想搞组合，**优先试博查 AI**。原因很简单：

1. 你的场景 90% 是中文信源（招投标公告、上市公司公告、企业新闻）
2. 博查的中文收录深度优于 Google/Bing，国内直连稳定
3. 返回结构化结果 + AI 摘要，减少你 Agent 的解析负担
4. 封装成 LangGraph tool 只需十几行代码

**AnySearch 不必弃用**，可以作为第二搜索源并行调用——当博查没命中时，用 AnySearch 的垂直领域覆盖来补。
