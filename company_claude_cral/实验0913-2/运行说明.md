## 依赖

```bash
pip install claude-agent-sdk httpx beautifulsoup4 lxml
```

需要本机 `claude` CLI（本实验用 2.1.270）与以下环境变量：

```bash
export ANTHROPIC_BASE_URL=...      # Anthropic 兼容网关
export ANTHROPIC_AUTH_TOKEN=...    # 或 ANTHROPIC_API_KEY
export ANTHROPIC_MODEL=...
```

> ⚠️ 密钥不要写进本目录任何文件。实验代码只从环境读取。

## 怎么跑

```bash
cd company_claude_cral/实验0913-2

# 全量：6 站 × 3 次 = 18 个独立 Agent 进程
python run_all.py

# 快速验证：只跑 1 次
python run_all.py --runs 1

# 只跑某站
python run_all.py --sites 000001 920139

# 只重新判分（不重跑 Agent）
python run_all.py --judge-only

# 单独跑一次（调试用）
python agent_crawl.py --code 000001 --name 平安银行 \
  --url "http://bank.pingan.com/bankPingAnCom/about/news" \
  --out results/000001/run1

# 单独判分
python judge.py 000001 results/000001/run1
```

## 判分口径

`单站通过 = list_pages_fetched >= 3 AND later_page_unique_urls >= 5`

- `list_pages_fetched`：去重后的列表页数（`final_url` 去重，防"重复请求同一页"）
- `later_page_unique_urls`：抽到的 URL 中属于"第2页及以后独有"的数量（防"翻假页"）

详见 `实验设计.md` §5。

## 已知陷阱（实现时踩过的坑，务必注意）

### 1. 裁判的 HTML 实体解码

源站大量用 `&amp;` 连接 query 参数（如 `newsxx.php?catid=93&amp;id=319`）。
若裁判不做 `&amp;` → `&` 解码，`_key()` 生成的就与 Agent 侧不一致，
**会导致 100% 假阴性**（实测：真实 139/139 命中被误判为 0/5）。

→ `judge.detail_urls_from()` 与 `crawl_runtime.simplify_list_html()` 均已做解码。
**新增站点时务必先验证裁判能跑出非零 `later_only`。**

### 2. 裁判的真值深度要匹配 Agent 上限

`truth_for()` 的 `max_pages` 必须 ≥ `crawl_runtime.MAX_PAGES`，
否则 Agent 抓了 8 页、裁判只算 4 页，`later_only` 会被低估。

→ 判分处已固定用 `max_pages=MAX_PAGES`。

### 3. 新增站点前的自检清单

```bash
python -c "
import judge
for code in ['新站代码']:
    t = judge.truth_for(code, max_pages=8)
    print(code, [len(s) for s in t['per_page']], 'later_only=', len(t['later_only']))
"
```

**期望：** 可翻页的站 `later_only` 应显著 > 0；若为 0，则要么正则写错，要么该站是 JS 渲染（通道问题）。
