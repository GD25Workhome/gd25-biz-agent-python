# 日期缺失根因：平安银行样例

## 样例

- URL：`https://bank.pingan.com/about/news/1787727208700.shtml`  
  （实验 JSONL 中为 `http://bank.pingan.com/about/news/1787727208700.shtml`）
- 现象：`crawl_output.jsonl` 对应记录里 `published_at: null`
- 同条还伴随：`title` 误为「组织架构」；正文开头混入金融许可证公示

## 页面上其实有日期

详情 HTML 结构近似：

```html
<h3>平安银行2026年中报:业务经营保持稳健  践行高质量可持续发展</h3>
...
<h5>2026-08-26</h5>
```

即发布日写在 **普通 `<h5>YYYY-MM-DD</h5>`** 上：没有 `<time datetime>`，也没有 class/id 含 `date`/`time`。

列表页锚文本里也有 `2026-08-26 + 标题`，但抽链阶段未回填到详情字段。

## 代码侧为何抽不到

`ContentExtractor._extract_publish_date` 只扫描：

- `time[datetime]`
- `.publish-time` / `.pub-time` / `.date` / `.time`
- `[class*='date']` / `[class*='time']` / `[id*='date']` / `[id*='time']`

对平安这种裸 `h5` **选择器命中数为 0**，直接返回 `None`。  
也未使用：标题附近 `h5`、全页首个合理 `YYYY-MM-DD`、列表锚文本日期、trafilatura 日期元数据。

## 同源问题

1. **标题**：优先抓到导航 `h1`/title 类节点；真标题在 `h3`  
2. **正文**：通用主内容抽取把同页其它大段模块（许可证公示）卷进开头

## 结论

不是「网站没日期」，而是 **MVP 日期规则过窄，适配不了该站 DOM**。  
修复方向（记录备忘，未在本封存中改代码）：标题附近日期节点、全页日期启发式、列表锚文本回填、按站点白名单收紧抽链。
