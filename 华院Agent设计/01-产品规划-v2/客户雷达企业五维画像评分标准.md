# 客户雷达企业五维画像评分标准

## 1. 评分目的

企业五维画像用于判断一家企业是否值得纳入客户雷达的目标客户池并进行长期监测，不用于计算雷达项目的 S1–S4 等级。

五个维度总分为 100 分：


| 画像维度    | 满分      | 权重       |
| ------- | ------- | -------- |
| 业务表达复杂度 | 25      | 25%      |
| 内容更新频率  | 20      | 20%      |
| 预算能力    | 20      | 20%      |
| 智能化潜力   | 20      | 20%      |
| 标杆价值    | 15      | 15%      |
| **合计**  | **100** | **100%** |


## 2. 分档与权重对应关系

采用固定分档，不允许在分数区间内由 AI 或开发人员自由取分：

- **强**：取该维度满分；
- **较强**：取原高分区间的下限；
- **一般**：取原中分区间的下限；
- **弱/无依据**：取 0 分。

具体对应如下：


| 画像维度    | 强   | 较强  | 一般  | 弱/无依据 |
| ------- | --- | --- | --- | ----- |
| 业务表达复杂度 | 25  | 20  | 10  | 0     |
| 内容更新频率  | 20  | 16  | 8   | 0     |
| 预算能力    | 20  | 16  | 8   | 0     |
| 智能化潜力   | 20  | 16  | 8   | 0     |
| 标杆价值    | 15  | 12  | 6   | 0     |




## 3. 五维画像具体评分标准

每个维度只选择最符合的一档计分，不累计。同一维度同时满足多个档位时，取证据能够支持的最高档位。

### 3.1 业务表达复杂度（25分）

判断企业的业务、技术和成果是否需要通过展厅进行系统化、场景化表达。


| 档位    | 得分  | 判断标准                                                                   |
| ----- | --- | ---------------------------------------------------------------------- |
| 强     | 25  | 企业拥有多个业务板块、跨专业技术体系或大量代表性案例，业务之间存在复杂关系，需要通过系统化叙事、场景还原、数据可视化或互动体验才能清晰表达。 |
| 较强    | 20  | 企业拥有较复杂的产品体系、解决方案或专业技术能力，并有多个项目案例；仅通过普通图文较难完整说明，适合采用模型、影片、互动程序等多种形式展示。 |
| 一般    | 10  | 企业业务相对单一，产品、服务或案例数量有限，主要内容可通过常规图文、视频或产品陈列完成表达。                         |
| 弱/无依据 | 0   | 企业业务和产品结构简单，基本没有复杂展示需求；或现有信息不足，无法判断其业务表达复杂度。                           |




### 3.2 内容更新频率（20分）

判断企业是否持续产生需要对外展示的新项目、新产品、新技术、新成果或重大动态。原则上以最近 12 个月的公开信息为主要依据。


| 档位    | 得分  | 判断标准                                         |
| ----- | --- | -------------------------------------------- |
| 强     | 20  | 平均每月及以上出现新项目、新产品、新技术、重大成果或重要经营动态，展示内容需要高频更新。 |
| 较强    | 16  | 大致每季度出现新项目、产品、技术成果或阶段性重大动态，展示内容具有周期性更新需求。    |
| 一般    | 8   | 每年仅有少量项目、产品、成果或企业动态，展示内容更新需求较低。              |
| 弱/无依据 | 0   | 长期未发现有效内容更新；或公开信息不足，无法判断更新频率。                |




### 3.3 预算能力（20分）

判断企业是否具备承担展厅建设、升级及后续运营投入的能力。营业收入为优先依据；营业收入缺失时，可使用企业人数、资产规模、公开建设投入等信息辅助判断。


| 档位    | 得分  | 判断标准                                                           |
| ----- | --- | -------------------------------------------------------------- |
| 强     | 20  | 营业收入在 10 亿元以上；或虽缺少营收数据，但有可靠证据证明企业具备大型品牌建设、数字化建设或固定资产项目的持续投入能力。 |
| 较强    | 16  | 营业收入在 2 亿–10 亿元；或虽缺少营收数据，但有可靠证据证明企业具备较强的品牌、数字化或空间建设投入能力。       |
| 一般    | 8   | 营业收入在 5000 万–2 亿元；或具备一般项目投入能力，但暂未发现较大规模建设投入。                   |
| 弱/无依据 | 0   | 营业收入在 5000 万元以下、投入能力较弱；或缺少可靠信息，无法判断预算能力。                       |


营业收入缺失时，企业规模可按以下口径辅助映射：


| 企业规模     | 建议对应档位 |
| -------- | ------ |
| 1000人以上  | 强      |
| 200–999人 | 较强     |
| 50–199人  | 一般     |
| 50人以下或未知 | 弱/无依据  |


当营业收入和企业规模对应档位不一致时，以更新、更可靠的营业收入数据为主；存在明显冲突时进入人工核验，不自动取较高档位。

### 3.4 智能化潜力（20分）

判断企业是否具备数字化基础、AI应用条件，以及是否存在通过智能展厅提升展示、接待、运营和销售能力的空间。


| 档位    | 得分  | 判断标准                                                     |
| ----- | --- | -------------------------------------------------------- |
| 强     | 20  | 企业具有明确的 AI 或数字化战略，具备数据基础、信息系统和多个可落地应用场景，并已开展或计划开展智能化建设。  |
| 较强    | 16  | 企业已经开展数字化建设，具备一定的数据或系统基础，并存在明确的智能化升级需求，但应用场景或建设计划尚未完全成熟。 |
| 一般    | 8   | 企业具备基础信息化条件，但尚未发现明确的 AI 战略、智能化项目或近期建设计划。                 |
| 弱/无依据 | 0   | 企业数字化基础薄弱、与智能展厅场景匹配度较低；或缺少有效信息，无法判断智能化潜力。                |




### 3.5 标杆价值（15分）

判断项目完成后是否具备品牌示范、行业传播、区域影响或同类客户复制价值。


| 档位    | 得分  | 判断标准                                                      |
| ----- | --- | --------------------------------------------------------- |
| 强     | 15  | 全国性行业头部企业、央企总部、国家级平台、国家级专精特新“小巨人”企业，或具有全国影响力和重大行业示范价值的单位。 |
| 较强    | 12  | 上市公司、区域龙头、省级平台、省级标杆企业，或在细分行业具有较强影响力和示范价值的单位。              |
| 一般    | 6   | 在所在城市、园区或细分领域具备一定代表性，项目完成后具有一定对外传播或同类客户参考价值。              |
| 弱/无依据 | 0   | 企业行业影响力、传播价值和项目复制价值有限；或缺少可靠信息，无法判断其标杆价值。                  |


> 国企、央企、上市公司等企业属性只作为标杆价值的判断依据之一，不直接替代对行业地位、项目示范性和传播价值的综合判断。



## 4. 画像总分与等级

企业画像总分为五个维度得分之和：

> 企业画像总分 = 业务表达复杂度 + 内容更新频率 + 预算能力 + 智能化潜力 + 标杆价值


| 画像等级 | 总分区间   | 业务含义                  | 默认入池动作         |
| ---- | ------ | --------------------- | -------------- |
| 核心   | 80–100 | 多个维度达到强或较强，具备较高长期监测价值 | 系统推荐进入目标客户池    |
| 重点   | 60–79  | 整体价值较好，部分维度仍需补充或持续观察  | 系统推荐进入目标客户池    |
| 观察   | 40–59  | 具备一定潜力，但当前证据或综合价值有限   | 需人工评估是否进入目标客户池 |
| 非目标  | 0–39   | 当前长期监测价值较低，或有效信息明显不足  | 默认不进入常规监测      |




## 5. 证据与评分执行规则



### 5.1 证据状态

每个维度的得分必须关联证据，并记录证据状态：


| 状态   | 含义                  | 评分处理              |
| ---- | ------------------- | ----------------- |
| 已确认  | 有企业材料、权威数据或可靠原文直接支撑 | 可作为正式评分依据         |
| 系统推断 | AI 根据有限公开信息推断       | 可生成候选分，但必须标记待核实   |
| 信息缺失 | 没有足够信息判断            | 暂按 0 分，并显示缺失项     |
| 信息冲突 | 不同来源的关键信息不一致        | 暂不形成最终入池结论，进入人工核验 |


“信息缺失”按 0 分只是为了完成候选分计算，不代表企业实际能力为 0。系统必须把“明确较弱”和“无信息依据”分别保存、分别展示。

### 5.2 建议证据来源


| 画像维度    | 优先证据来源                          |
| ------- | ------------------------------- |
| 业务表达复杂度 | 企业官网、企业介绍、产品与解决方案页面、年度报告、代表案例   |
| 内容更新频率  | 企业官网新闻、官方公众号、权威媒体报道、项目公告及成果发布记录 |
| 预算能力    | 年度报告、企业信用信息、公开营收与人员规模、重大项目和采购信息 |
| 智能化潜力   | 数字化战略、AI项目、信息化建设公告、技术平台和应用案例    |
| 标杆价值    | 企业属性、上市状态、行业排名、权威奖项、国家或省级平台认定   |




### 5.3 系统执行要求

1. 每个维度只能命中一个档位，多个条件同时满足时取证据能够支持的最高档位。
2. AI只输出候选档位、候选分数和证据，不得在固定档位之间生成任意分数。
3. 每次评分必须保存五维得分、总分、画像等级、命中档位、证据、证据状态和规则版本。
4. 人工确认或调整画像档位时，应保留系统原结果；发生人工调整时必须填写调整原因。
5. 企业信息或证据发生变化后，使用当前生效规则重新评分，并保留历史评分记录。
6. 企业画像只决定是否进入目标客户池，不得改变项目的 S1–S4、A/B/C 或销售行动级。
